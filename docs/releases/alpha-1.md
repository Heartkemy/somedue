# Alpha 1

The first downloadable Somedue preview for Apple Silicon and Intel Macs.

- Local tasks, projects, areas, headings, tags and checklists.
- Today, Upcoming, start dates, deadlines and local reminders.
- Markdown notes, keyboard navigation and Quick Entry.
- Dark and light appearance, with four views illustrated in the README.

Downloads work locally and do not connect to Things Cloud. Experimental Cloud
sync remains available in source development builds.

These are ad-hoc signed, unnotarized previews. macOS may block opening them;
Homebrew does not remove quarantine or bypass that decision. See the README for
installation and Apple's guidance. The declared minimum is macOS 13; native
Intel and oldest-OS coverage is limited. Keep backups of important tasks.

Report bugs and contribute through the repository. This is an early alpha:
features and data formats may change.
